# 3-Fold Walk-forward 프로토콜

2026-11-04 구현. 발전소 예측 정확도를 주목적으로 삼고 정산은 별도로 평가한다. 미래를 제외한 나머지 전체를 학습하는 K-fold가 아니다.

| Fold | 최종 학습 cutoff (KST, 포함) | 평가 구간 (KST, 종료시각 표기) |
|---|---|---|
| F1 | 2022-05-31 17:00 | [2022-06-01 01:00, 2023-06-01 01:00) |
| F2 | 2023-05-31 17:00 | [2023-06-01 01:00, 2024-06-01 01:00) |
| F3 | 2024-05-31 17:00 | [2024-06-01 01:00, 2025-06-01 01:00) |

실제 발전량 최초 관측은 2021-01-19 13:00 KST, SMP는 2021-01-01 01:00이다. 공통 학습 설정 시작일은 2021-01-01이다. 발전소 전체가 과거에 존재한 것은 아니다.

| Fold | 평가 시간 | 관측 site-hour | CF 0~1 유효 학습 행 | 학습 관측 발전소 / 미관측 발전소 | complete-fleet 시간 |
|---|---:|---:|---:|---:|---:|
| F1 | 8,760 | 677,327 | 287,656 | 45 / 208 | 0 |
| F2 | 8,784 | 1,256,595 | 964,536 | 106 / 147 | 0 |
| F3 | 8,760 | 2,170,645 | 2,220,438 | 205 / 48 | 3,802 |

각 Fold 내부 학습은 해당 연도 3월31일17시까지, Epoch 선택은 4월1일00시부터 5월31일17시까지다. 마지막 운영일의 18~24시 정답은 물리적으로 NaN 마스킹한다. 선정 Epoch로 전체 과거를 처음부터 refit한다. 정규화, 운량 teacher, 실측 보조 정답, 발전소 outage 판정도 각 단계의 cutoff 이전에서만 산출한다. 추론 입력은 발행시점이 확인된 10/17시 예보, 태양 위치, 달력, 발전소 메타데이터, 예측 기상뿐이다.

F1 전체 연도 지표는 보존하되 **F2 가중치 선택에는 F1의 2023-05-31 17시까지 8,753시간만** 사용한다. F2→F3도 2024-05-31 17시까지 8,777시간만 사용한다. 그렇지 않으면 직전 Fold 마지막 7시간 정답을 다음 Fold cutoff 뒤에서 가져오게 된다.

가중치: F1에서 선택→F2에 고정 적용, F1/F2에서 선택→F3 고정 적용. 사이트 NMAE의 Fold macro 평균을 우선하며 최악 Fold로 동률을 해소한다. W 최소와 사전 고정 0.8×정규화 Site NMAE+0.2×정규화 W는 별도 전략이다. W 전략은 시간 수 차이를 고려한 시간당 W 평균이다. F3를 선택 입력으로 주면 거부한다. F3는 과거에 이미 반복 분석되었으므로 새로운 독립 Holdout이 아니다.

평가는 실제 정답이 있는 행만 사용한다. site NMAE=100×mean(abs(error)/capacity), CF MAE=NMAE/100, MAE는 kWh이다. 주간은 사전 정의된 시간구간 내 태양고도 최대값>0으로 판정한다. CF≥0.5 부분집합은 사후 진단만 사용한다. 야간, 신규/90일 미만 이력, 월/계절/시간대/규모별 결과를 분리한다.

정산은 기존 comparison.core.evaluate를 재사용한다. 동일 관측 site의 예측/정답만 그룹 합산한다. W=sum(0.1×SMP×k×abs(group error)), k=KST11~15시3, 나머지1. S는 동일 ledger의 기존 정산식이다. 그룹 ratio NMAE와 시간별 macro NMAE를 따로 기록한다. complete-fleet는 참고만 사용하며 F1/F2는 유효시간0이다.

용량만 사용하는 deterministic 배정(metadata_primary)을 선택 기준으로 사용한다. SJ 최종 배정은 253개/중복없음/각20MW 이상을 검사하되 F1/F2에 사후 적용한 참고 정산이다. SJ 생성 로그가 없어 선언된 2024-05-31 cutoff의 독립 증명은 부족하다. 메타데이터 자체의 과거 유효 시점도 확인되지 않았으므로 그룹 평가의 한계다. 발전소 지표는 그룹과 독립적이다.

W_ref=223892580.02742994는 원본 baseline 예측과 계약을 재계산해 일치시킨 proof가 있을 때만 F3 observed-only 내부점수에 사용한다. 다른 연도와 complete-fleet에는 적용하지 않는다.
